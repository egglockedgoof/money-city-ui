# Native sensor kit (Swift)

The BareMetal sensor modules — raw motion, GPS/heading, mic levels, ARKit LiDAR depth, BLE scan, device state — kept by sin's standing order: wired, working, NOT integrated into the room yet. Folded here 2026-11-13 from the retired BareMetal repo when Rook's Capacitor build replaced the WKWebView shell as the app. The shell app itself is buried; this kit is the part with a future.
